What's Actually Left

06 Backfill historical detector hits

Without this, calibration (phase 7) has to wait months to accumulate enough samples per strength bucket (CALIBRATION_MIN_BUCKET_SIZE = 30). A one-time workflow_dispatch job scans years of history for the pilot tickers and writes every detector hit.

07 Close the calibration loop

The mechanism already exists in code — ConfluenceRanker accepts strength_hit_rates, and the live route already calls load_strength_hit_rates(). It currently reads a JSON file that doesn't survive a container restart. Point it at the new calibration table instead — a small change with disproportionate payoff.

08 Auth + synced user state

Supabase Auth on the frontend, RLS-scoped profiles/watchlist tables already exist in the schema from Phase 2. Dexie stays as an offline cache for signed-out use — no regression for anonymous users.

09 Scale the universe

From 5 pilot tickers to the full 954-ticker seed (browse it), sharded across parallel signals-scan.yml jobs to stay under the Actions job time cap. Cost/rate-limit envelope already sized in the plan doc.

10 Wire the multi-timeframe matrix

The last defect from the original audit — fully-implemented code with no caller. Closes it and gives CouncilPanel and SignalMatrixRow real data for the first time.
